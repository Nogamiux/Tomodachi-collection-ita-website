Guida all'installazione

Requisiti:

  • Rom .nds di Tomodachi Collection 1.1
    (NON OFFRIREMO ALCUN AIUTO SU COME TROVARE ONLINE IL GIOCO, DEVI POSSEDERE LA TUA COPIA)
  • La patch italiana del gioco, la potete trovare nelle releases(Attualmente non disponibile).
  • Un patcher Xdelta, ne esistono di numerosi, consigliamo xdelta-wasm (o strumenti web simili).

Procedimento:

  1. Una volta ottenuto tutto il necessario bisognerà accedere al sito linkato sopra.
  2. Nella voce "Source File" inserire la rom .nds di Tomodachi Collection 1.1.
  3. Nella voce "Patch file" inserire il file .xdelta scaricato nella pagina delle releases.
  4. Premere "Apply Patch", il download del gioco dovrebbe iniziare e sarete pronti per giocare.

Come Tradurre (Dietro le quinte)

Curiosi di sapere come abbiamo tradotto il gioco o volete cimentarvi anche voi? Ecco i passaggi tecnici fondamentali!

1. Estrazione dei file BMG

I testi del gioco sono contenuti nei file BMG (blocchi di testo). Per estrarli dalla ROM, è necessario utilizzare tool come Tinke o NsmbEditor.

2. Modifica ed Esportazione

I file BMG vanno aperti con strumenti specifici. Noi consigliamo caldamente bmgeditorarquivo, in quanto è pienamente compatibile; altri editor potrebbero generare corruzioni indesiderate.

Con bmgeditorarquivo è possibile convertire i BMG in file .txt, rendendo la traduzione molto più comoda. Tuttavia, avrete bisogno di un editor di testo che supporti la codifica UTF-16LE.

💡 Parentesi sulle codifiche (UTF-8 vs UTF-16 vs UTF-16LE):

  • UTF-8: È lo standard universale del web, molto compatto (usa da 1 a 4 byte per carattere) e perfetto per i testi occidentali.
  • UTF-16: Usa 2 o 4 byte per carattere. Viene spesso usato nei videogiochi per supportare meglio lingue con molti caratteri, come il giapponese.
  • UTF-16LE (Little Endian): È una variante dell'UTF-16 in cui l'ordine dei byte è invertito (il byte meno significativo viene salvato per primo). Questo è l'esatto formato che Tomodachi Collection richiede per leggere correttamente i file di testo!

3. Il problema della corruzione (Hex Editing)

⚠️ ATTENZIONE: bmgeditorarquivo "corrompe" la struttura del file BMG al momento del salvataggio. Tenere una copia non modificata del file originale è obbligatorio!

Per risolvere questo problema bisogna usare un Editor Esadecimale (Hex Editor):

  1. Aprite sia il file BMG originale (non modificato) sia quello modificato nel vostro Hex Editor.
  2. Nel file non modificato, cercate la stringa MID1 verso la fine del file.
  3. Copiate tutto il blocco di dati a partire da MID1 fino alla fine.
  4. Incollatelo nel file modificato, sovrascrivendo la sua parte finale e ripristinando la struttura corretta del file.

4. Re-inserimento dei testi

Una volta sistemato il BMG tramite l'editor esadecimale, non vi resta che applicare tutto re-inserendo il file all'interno della ROM utilizzando nuovamente Tinke o NsmbEditor ed il gioco è pronto!
